# Heatmap of `tuptime`

I've been running `tuptime` on many of my machines for years. It gives you a glance about how long ago you installed your machine, and how long it is running without interruption - maybe because of a power out.

Since I'm working on a heatmap display of my life in this repository, why not also one of my machines? Let's start with the Raspberry Pi 4 in my network.
